Import applications

Import applications from a UTF-8 CSV file. Existing records are preserved.

Export CSV

Upload CSV

Required columns: company, position, applied_date (YYYY-MM-DD). Optional columns: location, status, job_url, notes, follow_up_date, interview_date.

Accepted statuses: Wishlist, Applied, Interview, Offer, Rejected, Withdrawn. Files must be UTF-8 and at most 2 MB / 5,000 rows. Empty status defaults to Applied.

Duplicates (same company, position, and application date, ignoring capitalization) are skipped. If any row has invalid data, nothing is imported. Existing records are never overwritten.

To create a starter CSV, click Export CSV in the navigation. It includes every supported column, even with no saved applications.
